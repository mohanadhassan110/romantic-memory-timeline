# Romantic Memories Timeline - Laravel Backend (PHP)

خادم وقاعدة بيانات الخط الزمني للذكريات الرومانسية مبني بـ **Laravel 12** و **SQLite**.

---

## 🚀 طريقة تشغيل السيرفر (Quick Start)

افتح موجه الأوامر (Terminal / PowerShell) في مجلد `backend` وشغل الأمر التالي:

```bash
php artisan serve --host=0.0.0.0 --port=8000
```

> **ملاحظة:** إضافة `--host=0.0.0.0` تسمح لك بفتح الرابط من هاتفك المحمول أو أي جهاز متصل معك على نفس شبكة الواي فاي (Wi-Fi).

---

## 📱 كيف تفتح الموقع وتتزامن مع الموبايل؟

1. اعرف الـ IP لجهاز اللابتوب الخاص بك في الشبكة عبر تشغيل:
   ```bash
   ipconfig
   ```
   (ابحث عن `IPv4 Address` مثلاً `192.168.1.15`).

2. افتح لوحة الإدارة في الموقع على الموبايل أو اللاب:
   - اذهب إلى تبويب **"خادم Laravel (PHP)"**.
   - ضع الرابط مع الآي بي الخاص بك:
     ```text
     http://192.168.1.15:8000/api
     ```
   - اضغط **"فحص وتحديث الاتصال"**.
   - ستظهر لك النقطة الخضراء 🟢 **"متصل بخادم Laravel"**.

الآن أي ذكرى تضيفها أو تمسحها من الموبايل ستُحفظ في قاعدة البيانات فوراً وتظهر على اللابتوب والعكس!

---

## 📂 قاعدة البيانات (Database)

قاعدة البيانات عبارة عن **SQLite** موجودة في:
`database/database.sqlite`

لا تحتاج تثبيت MySQL ولا إدخال كلمات سر.

إذا أردت إعادة إنشاء الجداول في أي وقت:
```bash
php artisan migrate
```

---

## 🔗 نقاط الـ API (Endpoints)

- `GET /api/timeline` : جلب كافة الذكريات وإعدادات الشريكين (مع توليد البيانات الأولية تلقائياً).
- `POST /api/memories` : إضافة ذكرى جديدة.
- `PUT /api/memories/{id}` : تعديل ذكرى.
- `DELETE /api/memories/{id}` : حذف ذكرى.
- `DELETE /api/memories` : مسح جميع الذكريات.
- `POST /api/settings` : حفظ إعدادات الشريكين ورسالة الحب والـ PIN.
- `POST /api/reset` : إعادة ضبط الذكريات إلى النماذج الافتراضية.
