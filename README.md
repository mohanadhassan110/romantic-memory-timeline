# لحظاتنا معاً • Moments of Us 🌹

> تطبيق ويب رومانسي فاخر وتفاعلي مصمم كهدية رقمية تُفتح عبر بطاقة ذكية (NFC Card / Tag) لتوثيق رحلة حب استثنائية.
> A romantic, luxury digital memory timeline designed as an NFC gift for anniversaries and special moments.

---

## 🌟 مميزات المشروع (Key Features)

- **دعم كامل للغة العربية (Native RTL)**:
  - خطوط عربية عصرية ودافئة من Google Fonts (`IBM Plex Sans Arabic`، `Amiri`، `Tajawal`).
  - محاذاة واتجاه نصوص طبيعي `dir="rtl"` باستخدام الخصائص المنطقية الحديثة (Logical CSS / Tailwind CSS).
  - دعم النصوص ثنائية الاتجاه (BiDi Support) لحماية علامات الترقيم والأرقام والكلمات الإنجليزية من الانقلاب.
- **خط زمني تفاعلي وقصصي (Vertical Memory Timeline)**:
  - تناوب يميناً ويساراً على شاشات الكمبيوتر، وتراصف رأسي أنيق ومريح للمس على شاشات الجوال.
  - بطاقات ذكريات بصور عالية الدقة وتكبير (Lightbox Modal) وتفاصيل اليوم والمكان.
  - فرز وتصنيف ذكي للذكريات (محطات فارقة، البدايات، مواعيد غرامية، رحلات، لحظات خاصة).
  - شريط بحث فوري في الذكريات.
- **عداد الحب المباشر (Live Relationship Counter)**:
  - يحسب بالثواني والدقائق والساعات والأيام الوقت المشترك منذ بداية القصة.
- **مظروف الحب الشمعي (Wax-Sealed Love Letter)**:
  - مظروف بريد جوي بختم شمعي يتفتح مع مؤثرات صوتية واحتفالية للكشف عن رسالة ورقية معتقة بخط أميري كلاسيكي.
- **موسيقى وأجواء رومانسية (Ambient Soundscape)**:
  - مشغل نغمات هادئة باستخدام Web Audio API دون الحاجة لملفات خارجية.
- **لوحة إدارة سرية متكاملة (Secret Admin Studio)**:
  - وصول محمي برمز PIN سري (`1204`).
  - نموذج لإضافة ذكريات جديدة مع ضغط الصور تلقائياً على المتصفح لضمان أسرع تحميل عبر NFC.
  - إمكانية تعديل وحذف الذكريات، وتعديل أسماء الشريكين وموعد الذكرى السنوية.
  - تصدير واستيراد النسخ الاحتياطية (JSON Backup & Restore).

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل السيرفر التجريبي
npm run dev

# 3. بناء النسخة الإنتاجية
npm run build
```

---

## ☁️ النشر على Vercel (Deployment)

تم تضمين ملف `vercel.json` لضمان عمل التوجيه الداخلي (SPA routing) تلقائياً على سيرفرات Vercel:
1. ارفع المشروع على مستودع GitHub الخاص بك.
2. توجه إلى [Vercel](https://vercel.com) واختر **Import Project**.
3. سيتعرف Vercel تلقائياً على إعدادات `Vite` وسينشر التطبيق فورياً على رابط عالمي سريع.

## 🔑 بيانات الدخول الافتراضية
- **رمز PIN السري للوحة الإدارة**: `1204`
- **الوصول للوحة الإدارة**: عبر النقر على رمز الدرع في أعلى الصفحة، أو زر "المفتاح السري للإدارة" في التذييل، أو إضافة `#admin` في نهاية الرابط.
